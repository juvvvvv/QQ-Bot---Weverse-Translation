# v2 需求对照

| 本次确定的规则 | 实现 |
| --- | --- |
| 不加 / 或 wv 前缀 | commands.py 精确识别消息开头完整指令；译文只解析一次，井号保留。 |
| 截图链接只发原图 | 截图 + 链接；查看编号也只返回原图。 |
| 烤制链接 + 换行译文 | 一条消息调用抓取、排版、水印与发图；可用 [评论1] 分段。 |
| help 防止忘记指令 | 从同一指令注册表生成，按当前权限过滤。 |
| 打开仓库 | 列出本群待翻译和部分翻译；未完成列表保留档案编号。 |
| 不要引用、发图、恢复指令 | 已从 QQ 指令注册表删除；重新截图 / 烤制即可。 |
| 永久清空所有档案 | 按本群全部记录删除，不受 200 条显示上限限制；清除全部输出版本及历史译文，不伤及其他群。 |
| level 1 | 修改本群 PNG Logo、位置、大小、透明度；可用 help。 |
| level 2 | 继承 level 1 + 全部普通功能，包括永久清空。 |
| level 3 与主人 | 最高等级，可赋予和取消他人权限；主人不会被成员指令降级。 |
| 设置权限 / 取消权限 -l 或 --level @ | 解析真正 OneBot at 段，验证 1/2/3；QQ 群管理员身份不自动赋权。 |
| 群内 PNG 上传、位置调整 | 同一条设置水印消息附 PNG；WebUI 同步管理，按群独立。 |
| 主人 QQ 绑定 | WebUI 填本人 QQ，NapCat 登录另一个机器人 QQ；OneBot 发送者号匹配。 |
| 原帖 / 评论 / 水印 / 存档 | 保留 v1 排版、人工上传、网页登录、艺人评论拼接与自动记录；真实 Weverse 待校准。 |
| Mac 与 HTML 说明书 | 中文安装 / 启动脚本，完整 v2 离线说明书；Mac 实机尚未验收。 |

清空后暂停本群自动记录，防止马上重新入库。其他群、水印、权限和登录不删除。外部备份 / 已下载图片不由清空操作擦除。
