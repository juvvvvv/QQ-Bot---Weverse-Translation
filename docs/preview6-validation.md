# Windows 更新版 · 3.0.0-preview6

Windows 使用 Python 3.14。依赖未变化，已安装成功的项目不用重装。此次只更新 Windows 包，Mac ZIP 保留 preview3。

## 本轮更新

- 艺人和粉丝原帖均可读取。按网页结构辨认，不依赖 artist/fanpost URL 路径或页面语言；继续移除语言参数。粉丝头像、昵称、会员标识、发帖时间、完整正文、配图与原帖互动栏保留，中文排在原文后面。
- 评论仅收录有明确官方艺人标识的内容；粉丝会员和数字会员标识不会被误当成艺人。粉丝昵称与艺人同名也不会成为艺人头像来源。
- 没有艺人评论时只生成原帖，需一段译文或 /k。明确计数为 0 可以读取；没有整个艺人区域时，需确认已加载的普通评论区域持续稳定、无忙碌状态、没有官方艺人卡片，才认定为 0。普通评论数量仅辅助内部加载判断，不恢复总评论数显示或粉丝评论截图。加载中、计数损坏和其他未知状态仍停止，保留已成功译文。
- 连续读取前检查浏览器连接。失效句柄自动重建；连接中断或超时最多重试一次，沿用 data/browser，保留已写入的拒绝偏好和登录资料。失败日志仅记录阶段和错误类型，不输出网页令牌。尚不能据此确定你此前那次错误的唯一原因；再次失败时，可用新日志定位。
- 保持当前评论次序、图宽、原文和下方中文、圆角框、楼中楼细线、正常互动栏，以及 /e、/k、补充烤制、仅保留最新成功版本和最后添加的 Arial 水印。中央隐私弹窗先拒绝，关闭后再拒绝底部 Cookie 条；登录提示条继续排除。

## 升级步骤

1. 关闭工作台终端及工作台打开的浏览器，备份旧项目 data。
2. 完整解压 Windows ZIP，确认 VERSION 为 3.0.0-preview6。
3. 同时替换 weverse_bot、static、docs 文件夹，以及 run.py、VERSION、requirements.txt、首次安装.bat、启动工作台.bat。
4. 保留旧 data 与 .venv，双击新版启动工作台.bat，使用新打开的首页。
5. 重新输入网址读取，再填写或复用最新译文。四个页面校准值保留，粉丝帖子自动适配；如有两条艺人评论需三段，没有艺人评论只填一段正文译文或 /k。

段与段之间单独一行 +。不要省略无需翻译的版块，用 /k 占位。若旧截图提示重新读取，请重新抓取网址，以获得新版排版数据。
