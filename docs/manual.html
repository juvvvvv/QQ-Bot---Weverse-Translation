01先理解它怎么工作

这不是自动机器翻译。你提供中文，机器人读取 Weverse，保留原文，在原文底下插入中文，再加上配图、艺人评论和文字水印。

网址 → 原文和艺人评论
→
一次输入分段译文
→
原文下方插入中文
→
最后加水印 → PNG / QQ

工作台用于管理设置、核对抓取和试排版；接入 QQ 后可以在群中发送截图、烤制与补充指令。NapCat 是提供 QQ 收发接口的软件；Playwright / Chromium 是机器人读取网页的独立浏览器。

本轮重点是正文和评论译制。Mac 使用 Python 3.13，Windows 使用 Python 3.14。请先试用，再继续核对真实页面的样式。

02在 Mac / Windows 上安装

Windows 使用 Python 3.14，解压整个项目后双击“首次安装.bat”，安装完成后双击“启动工作台.bat”。Mac 使用 Python 3.13；以下 .command 步骤适用于 Mac。更新已经正常运行的项目请参照 本次更新步骤，保留 data 和 .venv。

Windows：首次安装

安装 python.org 的 Windows Python 3.14，完整解压 Windows ZIP，先双击“首次安装.bat”，看到安装完成后双击“启动工作台.bat”。日常只运行启动文件。已有正常安装请按第 13 节升级，保留 data 和 .venv。

Mac：首次安装

先只安装工作台，不必一开始就安装 QQ 桥接器。你的“Mac Pro”可能是 Intel，也可能是 Apple Silicon；点击苹果菜单 → 关于本机，看“处理器”或“芯片”。Python 的 universal2 安装包通常同时支持两者。

下载并解压整个项目

把项目文件夹放到固定位置，例如“文稿 / PLAVE翻译工作台”。不要仅下载说明书，也不要直接在压缩包里运行。路径含中文或空格可以使用。

安装 Python

前往 python.org 的 macOS 下载页，安装 Python 3.13 的 macOS 64-bit universal2 安装包。最低支持 3.11。如果安装器提供 Install Certificates.command，也运行它，让 Python 使用正确的 HTTPS 证书。

你已经使用 Homebrew 的话，也可以用 brew install python@3.13。不要为了安装而关闭 TLS 校验。

双击“首次安装.command”

它会创建独立 Python 环境、安装依赖和 Chromium。首次下载需要联网，等待看到“安装完成”。如 macOS 提示权限或无法直接打开，可打开“终端”，输入 bash （末尾有空格），将该文件拖进终端，再按回车。

bash "/你的实际项目路径/首次安装.command"

不要照抄上面的占位路径；用拖拽生成你的实际文件路径。如果出现 HTTPS 证书报错，先完成 Python 安装器提供的证书安装。

双击“启动工作台.command”

浏览器会打开本机的工作台。日常只运行这个文件，不需要重复安装。

http://127.0.0.1:8800/

这个地址只在你的电脑有效，不是公网链接。使用时保持终端窗口打开。停止时在终端按 Control+C，不是 Command+C。

遇到“模块找不到”，先重新运行“首次安装.command”。不要安装到系统 Python，也不要复制来路不明的“一键修复”命令。

03第一次生成正文与评论翻译图

  1. 打开工作台 → 设置。保留已经抓取成功的四个正文选择器，勾选“自动读取艺人评论”，保存。
  2. 输入动态链接，选择关联群，再点“读取帖子与艺人评论”。没有 QQ 接入时可以选择本机排版；后续补充必须使用同一个群。
  3. 展开每段原文，核对作者、时间、表情、评论次序。第 1 段是正文，之后依次是艺人评论。
  4. 在唯一的译文输入框中输入全部译文，段与段之间单独写一行 +。14 条评论需要 15 段译文，没有评论就只填正文。
  5. 点击“生成翻译图片”，检查原文下方的中文、配图、评论框和水印，再下载 PNG。修改错字后直接完整烤制即可。

04连接 QQ：另外准备一个“插头”

本项目采用参考 Bot 提到的 OneBot v11 正向 WebSocket 架构。它不直接修改或控制 macOS QQ。你可以使用已有 OneBot 服务，也可以选择下面的 Docker NapCat 方案。

方案 A：已经有 OneBot v11

  1. 在 QQ 接入软件中启用 WebSocket 服务端 / 正向 WebSocket，不是“反向 WebSocket”。
  2. 同机服务一般使用端口 3001。在双方填写相同的 Access Token。
  3. 工作台 → 连接与设置，填写主人 QQ 号、启用群号、ws://127.0.0.1:3001 和 Token。
  4. 先点“保存全部设置”，再点“连接 QQ”。顶部应显示“已连接 · QQ 机器人号”。

方案 B：Mac 上使用 Docker Desktop + NapCat

先安装适合你芯片的 Docker Desktop for Mac 并启动。上游 NapCat Docker README 声明支持 Linux/amd64 和 Linux/arm64；Docker 会按 Mac 架构选择镜像，无需默认强制 x86 仿真。但此项目没有在你的 Mac 上验证过 QQ 客户端兼容性。

在终端输入 cd ，把解压后的项目文件夹拖进终端后回车，再运行：

docker compose -f docker-compose.qq.yml up -d

随项目提供的配置会把端口限制到本机，并把 QQ 配置保存在 data/napcat/。没有替你登录 QQ，也没有预设你的令牌。

  1. 打开 http://127.0.0.1:6099/webui，根据 NapCat 提示进入管理页。管理页初始登录 Token 可在本机查看 docker logs plave-qq；不要把包含令牌的日志发给别人。
  2. 用你自己的 QQ 账号扫码登录。推荐专门的机器人账号，自己确认该账号可以加入和发言于目标群。
  3. 在 NapCat 的“网络配置”添加 WebSocket 服务器，端口 3001，容器内监听 0.0.0.0，启用消息上报，设置强随机 Access Token，然后保存并启用。
  4. 容器内监听 0.0.0.0 是为了让映射端口生效；项目的 Docker 端口映射只暴露在 Mac 的 127.0.0.1。
  5. 工作台里的 WebSocket 地址填 ws://127.0.0.1:3001，Token 填上一步的 OneBot Access Token。它与 NapCat 管理页登录 Token 是两回事。
  6. 主人 QQ 号填“你本人”的账号；不要填成机器人账号。每行填一个启用群号，保存后连接。

NapCat 页面名称可能随版本变化，详细参见 NapCat 官方文档 和 Docker 仓库。此说明依据读取到的上游 README 和 WebSocket 模板编写，未执行真实 QQ 登录。

第一次验证

把机器人加进启用群。用主人账号发送 help。收到命令表后，才说明群消息通路可用。再用工作台生成一张演示图，关联该群并发送，确认图片真的出现。状态“已连接”不能代替图片发图验收。

重启工作台后需重新点“连接 QQ”。修改群、主人或 OneBot 地址 / Token 会断开旧连接，再次连接后生效。远程 OneBot 必须使用 wss://，不能在公网传明文令牌。

这个项目本身不要求 AI API Key。QQ 桥接软件与账号的登录、客户端更新及平台限制需按其自身说明处理。Mac 休眠或程序退出后，机器人会停止处理新指令。

05何时需要登录 Weverse？

公开动态能直接打开时，不需要为了截图额外登录。需要账号权限的内容，则在“连接与设置 → 打开登录浏览器”打开的独立 Chromium 中手动登录。支持 Windows 和 Mac。

系统 Edge 能打开网址，不代表机器人已经拥有相同会话；机器人用自己的浏览器。登录会话保存在 data/browser，不会自动从 Edge 复制。工作台不收集你的 Weverse 密码。

回到工作台读取同一个网址，核对完整正文和艺人评论。浏览器窗口打开不等于登录成功。不要同时启动多个工作台占用同一浏览器目录。

顺序与楼中楼

优先使用完整机器时间；没有机器时间时，按已确认的网页“后发在上”顺序反转，因此中英文或其他日期显示不会改变排序。有明确父评论 ID 时按楼分组；同一分钟反转原叠放顺序。数字 ID 不作为发出时间。

普通评论保留圆角浅色框；楼中楼向右缩进并保留细线。你提供的 HTML 没有父评论 ID，所以无法仅凭 @HAMIN 判断回复了哪条 HAMIN 评论。这时按时间排序、保留缩进并提示，不猜归属。头像与文字虽是并列元素，机器人读取的是包含两者的完整卡片。

边距、高清和弹窗

根据内容元素尺寸裁掉多余底部空白，保留与顶部相应的边距，不按单个网址写死。像素倍率默认 2，可选 1/2/3；原生浏览器渲染，调整后需重新读取，旧 PNG 不会自动变高清。配图仍受网站资源清晰度限制。

已知同意弹窗自动点击 Do not consent，再确认关闭；不能用隐藏代替拒绝。本轮已适配底部 Cookie 条，点击“不同意并继续”并等待整条消失；同时出现中央弹窗时分别拒绝。如果仍被遮挡，请提供 Bot 浏览器中提示的 outerHTML、网址和截图。

09打开仓库、查看和永久清空

“打开仓库”列出本群未完成档案；“查看 编号”只发送该档案的原图。WebUI 仍可以查看原图和成图、填写译文、下载 PNG。列表显示最近 200 条，但清空操作作用于全部档案，不受 200 条限制。

待翻译还没有生成译文。
部分翻译已有成图，但本档案仍有未译位置。
已完成本档案捕获的所有位置都有译文，不代表网站全部评论已经抓取。
清空仓库是永久删除。level 2、level 3 或主人在群里单独发送“清空仓库”，立即删除本群全部档案、原截图、译文存档及成图和历史译文。没有“忽略”或“恢复”。其他群数据、水印、成员权限及 QQ / Weverse 登录保留。共享原图仍被其他群使用时会保留文件，只删除本群引用。

清空后暂停本群自动记录，避免下次轮询立即重新建档。需要重新开启时，由主人在 WebUI 设置中移除“暂停自动记录的群号”对应行并保存。之后主动截图或烤制仍会建立新的档案。备份或外部已下载图片不会被这个操作删除。

WebUI 清空时选择群号，确认删除；“本机未关联群仓库”只清除未关联群的档案。若文件权限导致图片无法删除，会明确报告未完成清理，并保留待清理记录；修复文件权限后再次清空重试，不把部分失败说成成功。

自动记录范围

先校准列表链接选择器，再启用定时记录。默认每 300 秒，至少 60 秒，每次检查当前列表前 10 个有效链接。相同原文不重复，新评论建立新档案；一次网页截图可供各群独立建档使用。它不保证全量历史补全、分页或即时通知；Mac 和程序需保持运行。

10主人绑定与三级权限

等级能做什么
未授权 / 0不能使用机器人指令。QQ 群主或群管理员身份不自动赋权。
level 1help，以及设置、查看、调整本群文字水印。
level 2继承 level 1，再增加截图、烤制、打开仓库、查看、永久清空仓库。
level 3继承 level 2，再增加设置和取消他人权限。可以授予 1、2、3。
主人在所有启用群始终有最高权限；不能用权限指令降级或取消主人。

权限按群独立。A 群的 level 3 在 B 群不会自动有权限。“管理员”只指主人和 level 3 成员；等级越大权限越高。

主人和机器人是两个 QQ 号

NapCat 登录机器人账号，负责收发群消息。“连接与设置 → 主人 QQ 号”填写你本人的 QQ 号，负责发送管理指令。机器人比较 OneBot 上报的发送者 QQ 与这个配置，判断是否主人；不要求你修改 Python，也没有额外验证码绑定流程。

本机 WebUI 没有分角色登录；能操作这台电脑管理页面的人可以修改全部设置。保护本机访问权。普通群成员只通过 QQ 指令按等级使用功能。

11常见问题

双击脚本没反应 / 提示没有权限

打开“终端”，输入 bash ，拖入“首次安装.command”或“启动工作台.command”，回车。保持终端窗口，查看具体报错。此方法不用修改系统安全设置。

安装 Chromium 出现 403、超时或 TLS 报错

403 多为网络阻挡，超时多为下载不可达。下载通常访问 cdn.playwright.dev、storage.googleapis.com 等官方地址。检查你所在网络的访问限制；不要关闭证书验证或从不可信镜像取可执行文件。TLS 证书错误先运行 Python 安装器提供的 Install Certificates.command，再重试首次安装。

8800 端口被占用

可能有另一个工作台仍在运行。关闭你自己启动的旧终端进程，或者在项目目录运行：

.venv/bin/python run.py --port 8802

然后打开 http://127.0.0.1:8802/。换端口启动不会自动修改默认启动脚本。

QQ 连接失败 / 连接了但没回复

确认是正向 WebSocket，NapCat 已登录 QQ 且上报群消息；Docker 容器内服务器监听 0.0.0.0:3001，本机映射 127.0.0.1:3001；OneBot Access Token 两边一致；主人 QQ 号、启用群和成员权限正确。先用主人发送 help。不要运行两个相同 Bot 实例，否则可能双重回复。

网页无法读取 / 登录过期

先在独立登录浏览器里确认你能访问这条帖子，然后检查正文 / 艺人标识选择器是否变化。明确提示登录失效时重新登录；没有找到帖子也可能是选择器错误，不要只反复输密码。云端代理 403 不等于账号登录过期。

少了评论、原文被截断、图很长

检查展开全文、页面是否加载完、评论是否在独立弹窗或虚拟列表里。超长图片会被限制：上传 12 MB / 2400 万像素，生成最大高 40000 像素 / 4800 万像素，单图最多 201 个译文位置。必要时分批截图。发送到 QQ 的图片另限 16 MB。不要把未加载评论当成“没有评论”。

中文显示方块 / emoji 不对

Mac 通常自动使用 /System/Library/Fonts/PingFang.ttc。可在设置里指定你自己的中文字库路径。原文和译文都由 Chromium 使用系统彩色 emoji 字体绘制。/e 引用该段原文表情，组合字素不拆开换行。请先预览核对。

更新项目后旧页面显示错误

同时替换 weverse_bot 和 static，停止旧服务再重新启动，浏览器按 Ctrl+F5（Windows）或 ⌘Shift+R（Mac）刷新。本轮依赖未变，无需重装。保护原来的 data 文件夹。页面提示“已过期”时刷新，以获取新的本机会话。
