01先理解它怎么工作

这不是机器自动翻译。中文译文由你或群里的翻译人员提供，机器人负责取图、插入译文、加长图片、添加水印和发回 QQ 群。

Weverse 原帖 / 手动截图
→
填入群友译文
→
插入原文下方 + 水印
→
下载 PNG / QQ 发图
名称你可以把它理解成
WebUI / 工作台浏览器里的中文管理页面，用来管理截图、译文、成员和设置。
OneBot v11本程序和 QQ 客户端之间的“插头”。只安装本程序不能登录 QQ。
NapCat可选 QQ 接入软件。在 Docker 的 Linux 环境里运行 QQ，并提供 OneBot 接口。
Playwright / Chromium负责打开 Weverse、保留登录会话和给网页截图的独立浏览器。
档案编号每次截图生成的短编号；群里翻译和引用时要带上它。
目前的实际边界：云端无法访问 Weverse 和小红书，返回网络代理 403。因此真实 Weverse 页面尚未校准，不能承诺安装后直接自动抓取。手动上传和图片排版可先用；自动抓取需要按第 06 节校准，QQ 需要登录后实测。

02在 Mac / Windows 上安装

Windows 使用 Python 3.14，解压整个项目后双击“首次安装.bat”，安装完成后双击“启动工作台.bat”。Mac 使用 Python 3.13；以下 .command 步骤适用于 Mac。更新已经正常运行的项目请参照 本次更新步骤，保留 data 和 .venv。

先只安装工作台，不必一开始就安装 QQ 桥接器。你的“Mac Pro”可能是 Intel，也可能是 Apple Silicon；点击苹果菜单 → 关于本机，看“处理器”或“芯片”。Python 的 universal2 安装包通常同时支持两者。

下载并解压整个项目

把项目文件夹放到固定位置，例如“文稿 / PLAVE翻译工作台”。不要仅下载说明书，也不要直接在压缩包里运行。路径含中文或空格可以使用。

安装 Python

前往 python.org 的 macOS 下载页，安装 Python 3.13 的 macOS 64-bit universal2 安装包。最低支持 3.11。如果安装器提供 Install Certificates.command，也运行它，让 Python 使用正确的 HTTPS 证书。

你已经使用 Homebrew 的话，也可以用 brew install python@3.13。不要为了安装而关闭 TLS 校验。

双击“首次安装.command”

它会创建独立 Python 环境、安装依赖和 Chromium。首次下载需要联网，等待看到“安装完成”。如 macOS 提示权限或无法直接打开，可打开“终端”，输入 bash （末尾有空格），将该文件拖进终端，再按回车。

bash "/你的实际项目路径/首次安装.command"

不要照抄上面的占位路径；用拖拽生成你的实际文件路径。如果出现 HTTPS 证书报错，先完成 Python 安装器提供的证书安装。

双击“启动工作台.command”

浏览器会打开本机的工作台。日常只运行这个文件，不需要重复安装。

http://127.0.0.1:8800/

这个地址只在你的 Mac 有效，不是公网链接。使用时保持终端窗口打开。停止时在终端按 Control+C，不是 Command+C。

遇到“模块找不到”，先重新运行“首次安装.command”。不要安装到系统 Python，也不要复制来路不明的“一键修复”命令。

03第一次生成翻译图

先点击右上方“试用示例截图”。示例有正文和一条艺人评论，明确标为演示，非真实艺人发言。在两个文本框里填译文，点击“生成翻译图片”，切换原图 / 成图查看，最后下载 PNG。

使用你自己的截图

  1. 在 Weverse 中打开 PLAVE 艺人帖子，展开正文和需要的艺人评论，先核对艺人身份。
  2. 截图保存为 PNG、JPEG 或 WebP。尽量使用无损 PNG；不要重复压缩截图。
  3. 工作台 → 上传截图 → 选择文件。右侧会出现原图。
  4. 点击“正文”位置，再在原图中点击原文最后一行下方。橙色虚线就是译文插入位置。
  5. 评论需要翻译时点“添加艺人评论位置”，再点击那条评论原文的末尾。重复添加即可。
  6. 填标题、选择关联群（也可以不关联），点击“保存截图并开始翻译”。
  7. 填每段中文译文，点“生成翻译图片”。确认原文、原图、点赞数和评论数都还在，再下载或发 QQ。

图片上的点击位置会按原始像素计算，即使预览被缩小也可以准确选点。插入线不出现在最后图片里。译文插入后，下方所有原图内容整体下移；原图不会被覆盖或缩放。

第一次上传时正文位置默认为截图最底部，只是安全起点，不会自动识别原文。请点击真正的原文末尾，否则译文会被加到整张截图后面。图片含正文和评论时，需要为每一段分别选位置。

原图里的 emoji 和图片会保留原像素。中文字体默认使用 Mac 的苹方。译文中的 emoji 是否正确显示取决于字体，生成后检查；当前不保证彩色 emoji 排版。

04连接 QQ：另外准备一个“插头”

本项目采用参考 Bot 提到的 OneBot v11 正向 WebSocket 架构。它不直接修改或控制 macOS QQ。你可以使用已有 OneBot 服务，也可以选择下面的 Docker NapCat 方案。

方案 A：已经有 OneBot v11

  1. 在 QQ 接入软件中启用 WebSocket 服务端 / 正向 WebSocket，不是“反向 WebSocket”。
  2. 同机服务一般使用端口 3001。在双方填写相同的 Access Token。
  3. 工作台 → 连接与设置，填写主人 QQ 号、启用群号、ws://127.0.0.1:3001 和 Token。
  4. 先点“保存全部设置”，再点“连接 QQ”。顶部应显示“已连接 · QQ 机器人号”。

方案 B：Mac 上使用 Docker Desktop + NapCat

先安装适合你芯片的 Docker Desktop for Mac 并启动。上游 NapCat Docker README 声明支持 Linux/amd64 和 Linux/arm64；Docker 会按 Mac 架构选择镜像，无需默认强制 x86 仿真。但此项目没有在你的 Mac 上验证过 QQ 客户端兼容性。

在终端输入 cd ，把解压后的项目文件夹拖进终端后回车，再运行：

docker compose -f docker-compose.qq.yml up -d

随项目提供的配置会把端口限制到本机，并把 QQ 配置保存在 data/napcat/。没有替你登录 QQ，也没有预设你的令牌。

  1. 打开 http://127.0.0.1:6099/webui，根据 NapCat 提示进入管理页。管理页初始登录 Token 可在本机查看 docker logs plave-qq；不要把包含令牌的日志发给别人。
  2. 用你自己的 QQ 账号扫码登录。推荐专门的机器人账号，自己确认该账号可以加入和发言于目标群。
  3. 在 NapCat 的“网络配置”添加 WebSocket 服务器，端口 3001，容器内监听 0.0.0.0，启用消息上报，设置强随机 Access Token，然后保存并启用。
  4. 容器内监听 0.0.0.0 是为了让映射端口生效；项目的 Docker 端口映射只暴露在 Mac 的 127.0.0.1。
  5. 工作台里的 WebSocket 地址填 ws://127.0.0.1:3001，Token 填上一步的 OneBot Access Token。它与 NapCat 管理页登录 Token 是两回事。
  6. 主人 QQ 号填“你本人”的账号；不要填成机器人账号。每行填一个启用群号，保存后连接。

NapCat 页面名称可能随版本变化，详细参见 NapCat 官方文档 和 Docker 仓库。此说明依据读取到的上游 README 和 WebSocket 模板编写，未执行真实 QQ 登录。

第一次验证

把机器人加进启用群。用主人账号发送 help。收到命令表后，才说明群消息通路可用。再用工作台生成一张演示图，关联该群并发送，确认图片真的出现。状态“已连接”不能代替图片发图验收。

重启工作台后需重新点“连接 QQ”。修改群、主人或 OneBot 地址 / Token 会断开旧连接，再次连接后生效。远程 OneBot 必须使用 wss://，不能在公网传明文令牌。

这个项目本身不要求 AI API Key。QQ 桥接软件与账号的登录、客户端更新及平台限制需按其自身说明处理。Mac 休眠或程序退出后，机器人会停止处理新指令。

05登录 Weverse

  1. 先在你的 Mac 上启动工作台。云端无桌面的机器不能弹出本机登录窗口。
  2. 连接与设置 → “打开登录浏览器”。会打开一个独立的 Chromium 窗口，进入 PLAVE 社区。
  3. 在 Weverse 官方页面手动输入账号、密码以及验证码。本程序不在 WebUI 收集或保存你的 Weverse 密码。
  4. 确认能看到完整艺人帖子和评论。会话由浏览器保存在本机 data/browser/。
  5. 回到工作台校准页面选择器并成功抓取一条帖子，这才验证会话当前可用于该内容。

登录窗口不等于登录成功。普通公开帖子可能无需登录；账号有权限的内容可抓取，其他受限内容不绕过。登录失效会在无法找到帖子且检测到登录页时提示重新登录；其他页面变化会提示“登录或选择器异常”，避免把所有失败都误判成登录过期。

不要手动删除 data/browser/，除非你决定清除登录状态。不要同时用多个程序打开同一浏览器配置目录。

06网页截图校准：第一次可能需要一点帮助

Weverse 页面结构会变化，也可能使用虚拟列表或独立滚动区域。这里没有冒充已验证的固定选择器。手动截图路径已可使用；自动抓取必须在真实页面校准。如果这一节难以操作，可以请懂网页的朋友帮你只做一次，或者先使用上传截图。

CSS 选择器就是在网页里定位某个区域的“地址”。在登录浏览器中打开一条 PLAVE 的 From PLAVE 艺人帖子，按 ⌘⌥I（Mac）或 F12（Windows / Edge） 打开开发者工具，使用左上角“选择页面元素”的箭头，点选对应区域。在 Elements 中右键该元素 → Copy → Copy selector，复制到工作台。

字段必须选择什么
帖子卡片只匹配 1 个完整帖子区域：艺人头像、名字、正文、图片、点赞 / 评论信息。不要把评论列表或整个页面导航也包进去。
正文文字在帖子卡片内部匹配 1 个完整原文块。会把译文插入这个块的底边；不要匹配多个分散的段落或标题。
艺人标识卡片内部能证明作者是艺人的明确 Artist 标识或认证元素。必须同时适用于帖子与艺人评论。不要用任意用户名元素，否则无法可靠过滤粉丝。
作者姓名 / 身份在帖子与评论内匹配唯一作者名或含 data-member-id / data-author-id 的身份元素。不能只选择通用 Artist 徽章文字；历史译文必须区分不同艺人。
评论卡片每条评论独立的完整区域；机器人只保留里面有艺人标识的卡片。为空时只抓正文。
评论原文评论卡片内部唯一且完整的评论文字块。
展开全文按钮可选；只匹配帖子 / 评论卡片里的“展开全文”控件，不是点赞、评论、订阅或跳转按钮。
总评论数 / 艺人评论数可选，分别匹配唯一可见数字。默认根据你提供的已加载 DOM 配置；保留 1.8K 等网页显示值，不按已加载条数推算总数，未识别不会记为 0。
列表帖子链接用于自动记录。在 From PLAVE 动态列表中匹配详情链接，例如 /plave/artist/数字编号。发现后仍会进入详情页校验艺人标识。

怎样确认选择器有效？

在开发者工具 Console 中检查帖子卡片匹配数量。下面是演示方法，.your-post-card 是占位符，不是真实 Weverse 选择器：

document.querySelectorAll('.your-post-card').length

应为 1。在卡片内确认正文只匹配 1 个；确认只有艺人评论卡片包含你设置的艺人标识，普通粉丝评论不包含。复制完整选择器后通常需要简化，让“正文”或“艺人标识”选择器在各自卡片内部仍然有效。

保存设置后输入真实帖子链接抓取，核对原文、emoji、图片、点赞 / 评论信息和所有需要的艺人评论。页面元素未匹配、匹配多个正文、缺少艺人标识或图片未加载时会停止。抓到截图仍需人工核对完整性。

长评论、更多评论、弹窗怎么办？

当前实现会有限次滚动主页面，尝试点击明确配置的展开全文按钮，然后把艺人卡片截图依次拼成竖向长图。它不保证处理独立滚动的评论弹窗、隐藏“更多评论”分页按钮、虚拟列表或所有历史评论。可把“抓取时隐藏浏览器窗口”关掉观察行为；若无法完整获取，先手动展开并上传截图。

如果帖子选择器包住了评论区、原文被 CSS 截断或出现分页缺失，请重新校准，不要把截断截图当成完整档案。此项目不会按总评论数推断“全部艺人评论已获取”。

底部留白和高清截图

新读取动态按作者、文字和媒体实际边界去除多余底部空白，保留与顶部一致的边距，不针对单个网址写死高度。“连接与设置 → 截图像素倍率”默认 2，可选 1/2/3；保持页面排版宽度，使用浏览器原生高密度渲染，并同步换算译文坐标。原配图的实际清晰度受网站资源限制。更改后重新读取，不会把旧 PNG 自动变高清。

评论计数仅代表读取时的快照。若显示“未识别”，在 Edge 按 F12、Ctrl+Shift+C，选择“所有评论”或“艺人的评论”旁的数字，在 Elements 右键 → Copy → Copy outerHTML，将这两段、网址和局部截图提供给我即可。

07群聊短指令：不加任何前缀

所有指令都不加 /、# 或 wv。只识别消息开头的完整指令词；“截图一下”“今天要烤制图片”不会触发。每条消息只解析一次，后面译文里的 # 标签、换行或“截图”文字会原样保留。

指令说明 / 最低权限
截图 帖子链接仅返回原始截图，level 2。
烤制 帖子链接
下一行填写中文译文		一次完成截图、插入译文、加水印和发图，level 2。中文由你提供，不是机器翻译。
help显示你当前等级可用的全部指令和示例，level 1。
打开仓库列出本群待翻译与部分翻译档案，level 2。
查看 档案编号只返回原截图，即使已有翻译成图也不发送它，level 2。
清空仓库立即永久删除本群全部档案、成图和历史译文，level 2。没有恢复指令。
设置权限 -l 2 @成员主人或 level 3 管理员设置成员等级；数字可以是 1、2、3。
取消权限 -l 2 @成员主人或 level 3 管理员取消成员权限，数字须为该成员当前等级。
设置水印 @PLAVE_PixelDiary设置本群文字水印，level 1。
查看水印查看本群文字、位置、字号、字色、描边和透明度，level 1。
调整水印 5 0 80九宫格位置、字号（0 跟随译文）、透明度（80 即约 20% 不透明），level 1。

操作一：只要原截图

截图 https://weverse.io/plave/artist/实际帖子编号

操作二：直接得到翻译成图

烤制 https://weverse.io/plave/artist/实际帖子编号
今天我很开心。
#PLAVE #演唱会

把链接放在第一行，译文从第二行开始。同一条消息完成，不必先截图或输入档案编号。无需 @ 机器人。

权限设置的 @ 必须是真的

设置权限 -l 1 @成员
设置权限 --level 2 @成员
取消权限 -l 2 @成员

在 QQ 中真正选择要 @ 的成员，不能只手写昵称或“@123456”。一次处理一位成员。新等级会替换旧等级；取消时完整移除该成员在本群的机器人权限，不是只剥离某项继承能力。

08评论没有链接，怎样一起翻？

使用所属帖子链接。机器人会把正文记为 0，匹配到的艺人评论按这次顺序记为 1、2、3……，不需要评论有独立链接。这些是档案内序号，不是 Weverse 永久评论 ID。

只填普通译文时，整段内容对应正文。要同时填写评论，用独立一行的 [评论1]、[评论2] 分段；[正文] 可选：

烤制 https://weverse.io/plave/artist/实际帖子编号
[正文]
今天我很开心。
[评论1]
明天再见！
[评论2]
大家早点休息。

若不确定评论顺序，先用“截图 链接”或 WebUI 核对。填写不存在的评论序号会提示错误，不会把译文随便贴到别的位置。每张成图会提示全部完成或仍有未译评论。

烤制时，未填写的位置会尝试复用本群历史译文；必须同时匹配同一帖子、同一作者、同一原文和正文 / 评论类型。新填的译文优先。不同艺人或不同群不会混用。没有匹配历史时，空白评论保持未翻译；没有单独的“引用”“发图”指令。上传截图没有可靠作者 / 原文身份，不能自动匹配历史。

09打开仓库、查看和永久清空

“打开仓库”列出本群未完成档案；“查看 编号”只发送该档案的原图。WebUI 仍可以查看原图和成图、填写译文、下载 PNG。列表显示最近 200 条，但清空操作作用于全部档案，不受 200 条限制。

待翻译还没有生成译文。
部分翻译已有成图，但本档案仍有未译位置。
已完成本档案捕获的所有位置都有译文，不代表网站全部评论已经抓取。
清空仓库是永久删除。level 2、level 3 或主人在群里单独发送“清空仓库”，立即删除本群全部档案、原截图、全部成图版本和历史译文。没有“忽略”或“恢复”。其他群数据、水印、成员权限及 QQ / Weverse 登录保留。共享原图仍被其他群使用时会保留文件，只删除本群引用。

清空后暂停本群自动记录，避免下次轮询立即重新建档。需要重新开启时，由主人在 WebUI 设置中移除“暂停自动记录的群号”对应行并保存。之后主动截图或烤制仍会建立新的档案。备份或外部已下载图片不会被这个操作删除。

WebUI 清空时选择群号，确认删除；“本机未关联群仓库”只清除未关联群的档案。若文件权限导致图片无法删除，会明确报告未完成清理，并保留待清理记录；修复文件权限后再次清空重试，不把部分失败说成成功。

自动记录范围

先校准列表链接选择器，再启用定时记录。默认每 300 秒，至少 60 秒，每次检查当前列表前 10 个有效链接。相同原文不重复，新评论建立新档案；一次网页截图可供各群独立建档使用。它不保证全量历史补全、分页或即时通知；Mac 和程序需保持运行。

11常见问题

双击脚本没反应 / 提示没有权限

打开“终端”，输入 bash ，拖入“首次安装.command”或“启动工作台.command”，回车。保持终端窗口，查看具体报错。此方法不用修改系统安全设置。

安装 Chromium 出现 403、超时或 TLS 报错

403 多为网络阻挡，超时多为下载不可达。下载通常访问 cdn.playwright.dev、storage.googleapis.com 等官方地址。检查你所在网络的访问限制；不要关闭证书验证或从不可信镜像取可执行文件。TLS 证书错误先运行 Python 安装器提供的 Install Certificates.command，再重试首次安装。

8800 端口被占用

可能有另一个工作台仍在运行。关闭你自己启动的旧终端进程，或者在项目目录运行：

.venv/bin/python run.py --port 8802

然后打开 http://127.0.0.1:8802/。换端口启动不会自动修改默认启动脚本。

QQ 连接失败 / 连接了但没回复

确认是正向 WebSocket，NapCat 已登录 QQ 且上报群消息；Docker 容器内服务器监听 0.0.0.0:3001，本机映射 127.0.0.1:3001；OneBot Access Token 两边一致；主人 QQ 号、启用群和成员权限正确。先用主人发送 help。不要运行两个相同 Bot 实例，否则可能双重回复。

网页无法读取 / 登录过期

先在独立登录浏览器里确认你能访问这条帖子，然后检查正文 / 艺人标识选择器是否变化。明确提示登录失效时重新登录；没有找到帖子也可能是选择器错误，不要只反复输密码。云端代理 403 不等于账号登录过期。

少了评论、原文被截断、图很长

检查展开全文、页面是否加载完、评论是否在独立弹窗或虚拟列表里。超长图片会被限制：上传 12 MB / 2400 万像素，生成最大高 40000 像素 / 4800 万像素，单图最多 30 个译文位置。必要时分批截图。发送到 QQ 的图片另限 16 MB。不要把未加载评论当成“没有评论”。

中文显示方块 / emoji 不对

Mac 通常自动使用 /System/Library/Fonts/PingFang.ttc。可在设置里指定你自己的中文字库路径。原图 emoji 不会变；译文 emoji 不保证彩色渲染，必要时换字体或改成文字说明。先预览再发布。

更新项目后旧页面显示错误

重新运行首次安装脚本，确保依赖更新；停止旧服务再重新启动，浏览器刷新。保护原来的 data 文件夹。页面提示“已过期”时刷新，以获取新的本机会话。
