# Windows 更新版 · 3.0.0-preview7

Windows 使用 Python 3.14，依赖未变，无需重装。只更新 Windows ZIP，Mac ZIP 保留 preview3。

## 三项修复

1. **没有艺人评论仅生成原帖。** 上一版只允许已加载的普通评论区域作为无艺人评论证据，艺人动态没有这一区域时仍会超时。现改为原帖已加载、没有实际艺人评论卡片且状态稳定时允许只生成动态，既支持没有任何评论区域，也支持只剩空艺人标题/列表、没有计数。需要一段中文或 /k，不添加空艺人评论区。
2. **移除平台翻译入口。** 隐藏艺人/粉丝原帖和评论的“查看翻译 / See translation”控件，按组件选择器处理，正文中正常出现“查看翻译”这几个字不会被删掉。中文译文仍在完整原文下方。
3. **动态互动栏完整放在动态后、艺人评论前。** 使用你提供的 `community-artist-postId-_-action_bar_inner` 结构，将原帖栏放入截图文档流，保留原生图标和网页显示的点赞/评论数字，例如 10K+ 和 2.1K，不把它们推算为精确数量，也不当作艺人评论数。已有固定栏在卡片内部时去除重复显示，粉丝原帖使用对应 fanpost 结构。

无实际艺人评论的页面会给延迟内容约 5 秒加载机会；最低等待设置 5 秒也支持这一流程。已出现实际艺人卡片却计数损坏、明确有评论但列表不完整，或页面仍显示加载中时，继续等待并在超时后停止，保留最新成功存档，避免把已有艺人评论误当成零条。

图宽、正文和评论译文位置、配图、评论排序、圆角框、楼中楼连续细线、/e、/k、补充/重烤和最后添加 Arial 水印保留。自动拒绝隐私提示和浏览器恢复保留。

## 升级

1. 关闭工作台及它打开的浏览器，备份旧项目 data。
2. 完整解压新版，确认 VERSION 为 3.0.0-preview7。
3. 替换 weverse_bot、static、docs，以及 run.py、VERSION、requirements.txt、首次安装.bat、启动工作台.bat；保留旧 data 与 .venv。
4. 双击新版启动工作台.bat，保留已经成功的四个校准值。
5. **重新读取网址，再烤制。** 旧 PNG 不会自动删除翻译入口或补出互动栏。此前的最新成功译文仍可复用。

## 验证

141 项完整回归测试通过；补充的 7 项检查涵盖最低等待设置与固定栏残留背景，新的浏览器界面流程和旧版补充/重烤流程均通过。日志见 preview7-test-results.txt、preview7-focused-results.txt、preview7-ui-results.txt、preview7-regression-ui-results.txt。界面验证无评论艺人动态的中文与 /k、带评论粉丝原帖、计数 0/2、下载和错误段数保留成功版本。Windows ZIP 检查 CRC、源码语法、版本、启动文件 CRLF 和解压后共享程序启动。
