# 后续更新需求记录

本文件区分本轮 v3 已实现内容与此前仍待更新的独立需求。标为待更新的功能不能视为已实现。当前完整操作说明见 manual.html，评论译制试用步骤见 v3-validation.md。

## 截图修正：本次处理

- 用真实作者区域保留头像、艺人名称和身份标识，不能只截正文和配图。
- 移除截图中的 Weverse / PLAVE 站点导航、菜单和底部登录邀请悬浮框。
- 截图前自动点击官方 `Do not consent` 拒绝按钮；支持同意弹窗所在 iframe。
- 拒绝后的偏好由 Bot 的持久化 Chromium 浏览器保存；弹窗再次出现时重新处理。
- 不用 CSS 隐藏同意弹窗代替拒绝；无法拒绝或作者区域不可见时停止截图并说明原因。
- 公开动态可在未登录状态读取。需要账号权限的内容仍按网站要求登录。
- 真实网页仍需用户在本机验收。当前选择器仅根据所提供的 YEJUN 单段正文页面校准。

## 动态、编号与分类：待更新

- 产品中的“档案”概念全部替换为“动态”。
- 绑定 Weverse 社区，抓取艺人动态和艺人评论，按发布时间从先到后累计。
- 编号显示为 `0001`～`9999`，与发布时间相关；截图、烤制及分类变化不改变编号。
- `/待处理`：未截图、未烤制。
- `/待烤制`：已截图、未完成烤制。
- `/仓库`：汇总上述两类未完成动态。
- 烤制完成后退出仓库；动态编号、原图和成图保留。
- `/清除待处理`、`/清除待烤制`、`/清除仓库`：分别永久删除对应范围的数据和图片。
- `/清除仓库` 的范围不包含已经完成并退出仓库的动态。
- 分类指令和清除指令采用这次确定的 `/` 前缀；其他短指令沿用此前规则。
- 待确认：补抓更早动态时怎样兼顾时间顺序与已有编号；超过 9999 的处理规则。

## 文字水印与翻译名称：面板已更新，名称绑定待更新

- 去除 PNG Logo、水印图片上传及相关指令，只保留文字水印。
- 按最新要求，水印内容在面板自由输入，默认 `@PLAVE_PixelDiary`；不再强制固定文字或位置。
- 位置支持 1–9：第一行左上/中上/右上，第二行中左/中间/中右，第三行左下/中下/右下。
- 面板可调字号、字色、文字描边开关/颜色/粗细、透明度，字体同译文；字号 0 跟随译文。
- 新配置默认中下（位置 8），旧配置保留位置；透明度 80（20% 不透明）；0 完全不透明、100 完全透明。
- 已移除 PNG 上传、群内图片读取和 PNG 叠加；旧文件保留但不再参与生成。
- 水印在正文、译文、配图和评论全部排完后只加一次；可预览，再保存配置。
- 授权时名称必填，例如 `设置权限 -l 2 名字：小鱼 @群成员`。
- 保存 QQ 号、授权等级和翻译名称；每次烤制由发起人的 QQ 号找到绑定名称。
- QQ 群昵称变化不自动改变绑定的翻译名称；主人也需要配置翻译名称。
- 主人及 level 3 可授权他人，数字越大权限越高，保留权限继承规则。
- level 1 可设置文字水印内容、位置、字号和透明度，继承规则保留。

## 工作台与模拟群聊：待更新

- 真实 QQ 群承担日常截图、烤制、列表、清除及权限操作。
- 工作台提供模拟群聊入口：用户发指令/网址/译文，程序以机器人角色回复文字和图片。
- 默认以主人身份模拟，可切换 level 3、level 2、level 1 和无权限成员验证权限。
- 模拟与真实群使用同一套指令逻辑；模拟数据单独保存，避免测试清除真实动态。
- 保留管理设置、QQ 连接、Weverse 登录、抓取和运行状态入口。

## 烤制版式：本次进入程序，待真实样张核对

- 用户主要提供网址和人工译文，机器人自动读取网页；上传截图用于样式核对和备用。
- 参考例图：保留原文，白底追加中文，译文位于原文之后、配图之前。
- 根据译文实际长度扩展高度，配图和下方信息整体下移，保留图片比例。
- 移除旧版带标题的绿色翻译框和底部整理栏。
- 艺人评论的译文应与对应原文配对，不混入粉丝评论。
- 本次使用真实卡片截图，加上 Chromium 排版的白底译文块，再无损拼接。
  原文和配图保留，译文位置、字号和左边距取自已读取的正文。
- 译文 emoji 使用浏览器系统彩色字体，完整字素不会被换行拆开。
- 样本原文 `예쁜하루☺️`，译文 `漂亮的一天🙂`；仅显示译文内容，不添加“译文：”标签。
- 删除绿色翻译框、图片内的“中文翻译 · 正文”标题和底部“翻译整理”栏。
- 新抓取记录保存排版参数；旧记录缺少参数时使用通用边距与设置字号。
  测试同一动态时应重新读取，以获得原文实际字号和左边距。
- v3 已实现 `/e`：每段按对应原文表情顺序引用，支持 `/e/e`，未引用表情不追加。
- 工作台统一输入框，单独一行 `+` 分段；正文编号 1，评论编号 2 起。
- 新 QQ 格式为 `烤制|网址|`；译文开头独立一行 `+` 则复用最新存档并只补充新评论。
- 同群同网址按评论 ID 绑定，最新成功版覆盖旧版；错误或生成失败保留旧成功存档。
- 最新更新：按内容元素实际边界裁掉多余底部留白，保留与顶部一致的底部边距；适用于不同长度的动态，不按单个网址硬编码。
- 截图默认 2 倍像素，可选 1/2/3；保留 CSS 布局宽度，用原生高清渲染并同步换算译文插入坐标，不放大已有 PNG。
- 媒体清晰度受网页资源限制；真实 Weverse 的不同动态仍需本机验收。
- v3 删除总评论数，只读取艺人评论数，区分未知和 0；精确计数与捕获数量不符时停止。
- 自动展开艺人评论，在真实滚动区域尝试加载，保留完整头像、名称、身份标识、时间、原文、表情和链接。
- 普通评论圆角框；楼中楼缩进、细线。明确父 ID 可分组；缺失时不凭 @名字猜测归属。
- 由早到晚，同分钟以网页叠放顺序反转；最多 200 条评论，尚不保证所有分页或虚拟列表。
- 水印最后添加；位置 7/8/9 位于最终底部白色留白中，避免盖住配图。
- 未知底部收集提示按用户要求暂缓，待复现后提供 Bot 浏览器 outerHTML 再适配；已知 Do not consent 处理保留。

## 系统与 Python 版本

- Mac 以 Python 3.13 为安装、说明和排错基准。
- Windows 以 Python 3.14 为基准；沿用旧版程序的两个 `.bat` 已单独提供。
- 统一源码，分别提供 Mac / Windows 启动文件及相应安装说明、下载包。
- Windows 安装脚本已经修正为优先检查 3.14，并验证实际解释器与虚拟环境。
