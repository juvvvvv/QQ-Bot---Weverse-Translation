# 底部留白、评论数、高清截图和文字水印

## 本机更新

1. 关闭现有工作台，在终端按 Ctrl+C。
2. 下载并解压更新源码，将其中 **`weverse_bot` 和 `static` 两个文件夹**复制到原项目，合并并替换同名文件。可同时更新 `docs`，以查看新说明书。
3. 保留原项目的 **`data` 和 `.venv`**。本次没有新增依赖，不需要重新首次安装。
4. Windows 使用现有 `启动工作台.bat`（Python 3.14），Mac 使用 `启动工作台.command`（Python 3.13）。
5. 刷新工作台，必要时 Ctrl+F5 强制刷新。重新读取动态，再填译文生成；旧截图和旧成图不会自动变化。

## 动态布局与清晰度

不针对某条网址写死高度。程序测量作者、实际文字、媒体和评论数区域，去除网站 `min-height` 等产生的空白；底部保留与顶部一致的边距。媒体根据网页元素的边界保留，全白配图不会被当作空白删除。

“连接与设置 → 截图像素倍率”默认 2，可选 1、2、3。例如 CSS 宽度 420px 的卡片，2 倍输出约 840px 宽，排版宽度保持 420px。浏览器直接按高像素密度绘制文字和媒体，译文位置、字号、间距同步换算；不是将旧 PNG 拉大。高清模式也可能使页面选用更大的媒体资源，但不能把低清原图还原成高分辨率照片。

## 当前评论数

根据用户提供的已加载网页结构，默认填写了两个可调整的选择器：

| 字段 | 默认选择器 |
| --- | --- |
| 总评论数 | `.comment-total-count-and-refresh-_-count` |
| 艺人评论数 | `.base-comment-artist-count-and-toggle-_-count` |

数字显示在原图卡片底部和工作台译文编辑区，代表**读取时**网页显示的数量。重新读取可更新快照。`1.8K` 原样显示，内部约数为 1800；不是精确 1800，也不是本次已加载的评论条数。找不到数字时显示“未识别”，不会变成 0，也不会影响正文读取。只有网页真的显示 `0` 才记录为 0。

如果本机显示“未识别”：在 Edge 打开同一网址，按 F12，再按 Ctrl+Shift+C，点击“所有评论”旁的**数字**，在 Elements 中右键选中的元素 → Copy → Copy outerHTML。艺人评论数字也同样复制。提供这两段 HTML、网址及数字所在区域的截图即可；不需要整页源码、Cookie 或账号信息。

## 文字水印面板

在“连接与设置 → 文字水印”操作：

- 范围可选默认水印或某个启用的 QQ 群。未独立设置的群继承默认水印。
- 文字默认 `@PLAVE_PixelDiary`，可以输入多行文字，最多 200 字。
- 字体和译文相同。字号 0 跟随当前译文；手动设置为 8–96 CSS 像素，高清截图会同步放大实际像素字号。
- 字色、文字描边颜色可自由选；描边围绕每个字，粗细 0–8 CSS 像素，可关闭。
- 透明度 0 完全不透明，100 完全透明；默认 80，即约 20% 不透明。
- 位置按下面的数字排列，并以**最终整张图片**为范围：

| 1 左上 | 2 中上 | 3 右上 |
| --- | --- | --- |
| 4 中左 | 5 中间 | 6 中右 |
| 7 左下 | 8 中下 | 9 右下 |

“预览水印”使用当前动态及已保存译文；未打开动态时提供明暗背景示意。预览不会保存配置，也不会覆盖成图；点击“保存水印”，再回到译文页重新生成才生效。文字太长或字号过大导致水印放不下时，会提示缩短文字或减小字号，不裁掉文字。

已删除 PNG 上传和叠加功能。旧 Logo 文件仍保留在本机，但不会用于生成。

QQ 中 level 1 及以上可使用：

```text
设置水印 @PLAVE_PixelDiary
查看水印
调整水印 5 0 80
```

最后一条依次是位置、字号、透明度。水印只有一次合成：原帖和所有已选评论的译文、配图排完后，再按最终高度定位并叠加；没有额外底部整理栏。
