# Windows 更新版 · 3.0.0-preview8

Windows 使用 Python 3.14。本轮没有依赖变化，保留已经安装成功的 .venv，无需重新安装。

## 多图动态的底部互动栏

修复所有配图后面点赞、评论数字和分享图标被裁掉的问题。截图前等待卡片内全部图片加载和解码，随后测量实际内容；互动栏使用自然高度、禁止收缩，并保留底部空间。原生 SVG 按所属图标盒子的尺寸显示，避免图标伸出容器后被截掉。截图边界向上取整，包含允许范围内的实际图标底边，而不是截掉后仅补白。

这套处理使用实际图片和互动栏的布局，不根据一张、两张等图片数量写固定截取高度。正文中文仍放在完整原文下方；配图、评论排序、圆角框、楼中楼、/e、/k 和最后添加的 Arial 文字水印沿用当前方式。没有艺人评论仍只生成原帖；艺人及粉丝原帖共用互动栏处理。

## 升级步骤

1. 关闭工作台和它打开的浏览器，备份旧项目的 data 文件夹。
2. 完整解压新版，确认 VERSION 为 3.0.0-preview8。
3. 替换 weverse_bot、static、docs，以及 run.py、VERSION、requirements.txt、首次安装.bat、启动工作台.bat；保留旧 data 和 .venv。
4. 双击启动工作台.bat。页面校准的四个值继续使用已成功的设置，不必重新填写。
5. **重新读取多图动态的网址，再烤制。** 已裁切的旧 PNG 无法补回丢失的像素；最新成功译文仍可复用。

本轮只打包 Windows。Mac ZIP 保留原来的 preview3，不复制 Windows 的 .venv 到 Mac。

## 验证范围

- 使用实际结构的点赞 10K+、评论 2.1K、分享 SVG 互动栏，测试 0、1、2、5 张配图，在 1 倍和 2 倍像素倍率下完整显示。
- 给互动栏附加受限高度/裁切样式，给图标附加大于盒子的尺寸，验证修复后完整图标像素及底部留白；照片中间和最后一行保持。
- 两张配图的中文烤制和 /k 保留原帖像素；最后加中下水印，配图及互动栏不被覆盖。
- 旧实现允许的 2px 图标溢出会丢失最后两行，新实现完整保留。两项缺陷检查已在旧实现上复现失败，并在新版上通过。
- 模拟后台浏览器暂停动画帧，仍能完成截图，避免图片解码后的等待悬挂。
- 回归检查艺人/粉丝原帖、无艺人评论、原文及表情、评论排版、楼中楼、隐私提示拒绝、连续浏览器恢复、译文存档、/k 和水印。
- 实际启动 WebUI，验证双配图长动态及带艺人评论的粉丝原帖，填写中文、/k、下载图片，错误段数不破坏已完成版本；浏览器无脚本错误。

最终 20 项本轮及相关回归测试全部通过，WebUI 流程通过且无脚本错误。结果日志：preview8-regression-results.txt、preview8-ui-results.txt。打包检查另见 preview8-package-results.txt（此日志在仓库内）。Windows ZIP 检查版本、CRC、源码语法、两个 .bat 的 CRLF、无私有运行数据，并检查解压后共享程序的首页、设置及 HTML 说明书。

验证环境为 Linux Chromium 和受控网页，未在 Windows 本机运行 .bat，也未直接操作你的真实 Weverse/QQ 会话。
