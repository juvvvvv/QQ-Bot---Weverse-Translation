# Windows 最新修正版 · 3.0.0-preview2

## 修复了什么

1. **底部 Cookie 提示**：根据你提供的提示条，明确点击“不同意并继续”，不点击类名带 deny、实际显示“可选同意”的按钮。兼容类名末尾变化，核对 Cookie 政策区域；点击后确认整条提示消失。中央 consent 弹窗和底部条同时出现时分别拒绝，也处理 iframe 和延迟出现的提示。不以隐藏替代拒绝，网站写入的偏好由持久化浏览器保存。
2. **评论延迟加载**：从一次空列表查询改为持续等待计数、完整评论和短暂稳定状态。默认最多等 30 秒，设置里可调 5–120 秒。等待期间处理同意提示，并尝试滚动评论区。
3. **不再默默漏掉评论**：开启自动读取时，计数未知、缺少评论、身份/时间未加载或超时都停止截图，并给出具体原因。精确显示 14 条时必须读取到 14 条；明确稳定的 0 与未知分开。失败保留之前成功的译文存档。
4. **排序不依赖语言**：完整机器时间可用时优先使用机器时间；否则利用你确认的网页“后发在上”顺序反转。不会把 Sep 30 等本地化日期误当成排序失败，也不凭数字 ID 推测时间。同分钟反转原叠放次序；父 ID 明确时仍按楼分组。
5. **网址规则不变**：继续移除 `?hl=...` 及分享参数，同一个动态的不同语言链接归为同一个网址，方便引用最新译文。

## 已正常安装 Windows 的更新步骤

Windows 继续使用 **Python 3.14**；本次没有增加依赖，不需要重装 Python 或重新首次安装。

1. 关闭工作台：在运行终端按 Ctrl+C，并关闭工作台打开的 Weverse 浏览器。
2. 备份旧项目的 `data` 文件夹。
3. 将新版 ZIP 解压到另一个文件夹，确认 `VERSION` 是 `3.0.0-preview2`。
4. 把新版 `weverse_bot`、`static`、`docs` 三个文件夹完整替换到旧项目；同时替换 `run.py`、`VERSION`、`requirements.txt`、`首次安装.bat` 和 `启动工作台.bat`。
5. **保留旧项目的 `data` 和 `.venv`**，不要把别的系统的虚拟环境复制进来。
6. 双击“启动工作台.bat”。浏览器按 Ctrl+F5 刷新，避免旧界面缓存。

首次使用则完整解压 ZIP，先运行“首次安装.bat”，完成后运行“启动工作台.bat”。HTML 中文说明书在 `docs/manual.html`。
