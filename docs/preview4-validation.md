# Windows 反馈修正版 · 3.0.0-preview4

本轮仅生成 Windows 下载包，继续使用 Python 3.14。没有增加依赖；已安装成功的项目无需首次安装。仓库中的 Mac ZIP 保留上一版 preview3，不把本轮 Windows 包当作新版 Mac 包。

## 这次修复

1. **首页会话**：页面启动主动建立本机会话，浏览器未保存 Cookie 时也可以保存设置。旧标签页在程序重启后提交时，会重建会话并重试一次，保留已经输入的内容；截图预览、PNG 下载及水印预览也能在本机 Cookie 不保存时工作。仍保留本机访问、跨站阻挡、写请求校验，不以取消校验解决问题。
2. **两个隐私提示顺序**：根据你提供的 `.fc-consent-root`，先点击 `.fc-cta-do-not-consent`，等待对话框以及并列的 `.fc-dialog-overlay` 都不可见，才点击底部“不同意并继续”。允许根容器和隐藏设置页留在 DOM，不把它们误判成未关闭；真正残留的遮罩仍阻止截图。拒绝偏好继续保存在 `data/browser`，网站再次询问时重新自动拒绝。
3. **动态互动栏**：测量包含完整的点赞、评论工具栏盒子，不只依赖文字和 SVG 的局部尺寸，让底部留足空间。
4. **评论多余图形**：仅在用于截图的评论副本中去除伪元素产生的浅色曲线、额外半截图标，整理互动栏的尺寸与位置。卡片内正常的点赞、评论数保留；圆角框、楼中楼缩进和直线连接保留。
5. **评论头像**：恢复头像尺寸、可见性并等待加载。识别全透明占位图；从同一艺人的已加载评论或原动态头像补齐，不借用其他艺人的头像。仍无法找到真实头像时停止，避免保存缺头像的图。
6. **评论原文与译文**：释放截图副本中原文各层容器的限高和定位，测量完整原文的末尾，在其下插入中文。原文、表情和链接保留，卡片及直线随译文向下扩展，后续评论整体下移。宽度与排序保持。
7. **`/k`**：整段单独填小写 `/k` 跳过该段译文，仍保留动态或评论原文，不加空白译文区域，也不改变后续段落对应关系。保存跳过状态，补充新评论时复用；完整烤制可以把 `/k` 换成译文。全部段落都 `/k` 也可以成功生成原图加当前水印。
8. **Arial 水印**：水印独立使用 Arial，中文回退系统中文字体；译文字体和水印位置不变，仍在最终拼接完后添加。描边、颜色、透明度等面板继续可调。

## 已安装 Windows 的更新步骤

1. 关闭工作台终端和工作台打开的 Weverse 浏览器，备份原来的 `data`。
2. 将新版 ZIP 完整解压到另一个文件夹，确认 `VERSION` 是 `3.0.0-preview4`。
3. 把新版 `weverse_bot`、`static`、`docs` 完整替换到原项目；同时替换 `run.py`、`VERSION`、`requirements.txt`、`首次安装.bat`、`启动工作台.bat`。
4. 保留原项目的 `.venv` 和 `data`。双击新版“启动工作台.bat”，使用新打开的页面，关闭旧标签页。
5. 原来成功的四个页面选择器不需要改。再次输入网址，重新读取动态和评论，再烤制。

**旧 PNG 和旧截图坐标不会自动修正**。请重新读取网址；同一群和链接中已保存的最新译文可在完整模式自动填回，再校对提交。不要直接用旧截图验证新头像、底部互动栏和原文插入位置。

统一译文示例：

```text
烤制|https://weverse.io/plave/artist/3-241901329|

正文中文译文 /e

+

/k

+

第二条评论中文译文
```

正文加 14 条评论仍需要 15 段；无需翻译的段用 `/k` 占位，不直接删段。后续补充照原用法以独立一行 `+` 开头，只填写新增评论的译文或 `/k`。

真实 HTTP 服务与浏览器界面另验证：拒收所有 Set-Cookie 后的设置保存、原图与译图显示、PNG 下载、水印预览；程序重启但保留旧标签页和未保存输入，点击保存可重建会话并重试。

116 项自动回归测试全部通过；三组浏览器界面流程均通过，未发现浏览器控制台错误。实际结果见 `preview4-test-results.txt`、`preview4-ui-results.txt`、`preview4-smoke-results.txt`、`preview4-translation-ui-results.txt`。测试在 Linux Chromium 运行，头像用受控图片，未在 Windows 本机运行安装器；Arial 的实际字形请在 Windows 本机核对。真实 Weverse 网络、账户和 QQ 仍需本机验收，无法据离线测试承诺所有网页变体。
