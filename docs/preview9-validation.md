# Windows / Mac 更新版 · 3.0.0-preview9

Windows 使用 Python 3.14，Mac 使用 Python 3.13（Intel Mac 适用）。两包共用本版源码，各自包含对应系统的启动文件。依赖与上一版 Windows、旧 Mac preview3 相同，已安装成功的本机 .venv 可保留。

## 动态互动栏独立生成

上一版修正了 SVG 尺寸和截图边界，但互动栏仍位于原网页的外层容器中。外层 overflow / clip-path、固定高度或文字标签裁切可继续截住底部；浏览器甚至返回一张实际高度较短的 PNG。后续补白不能恢复已丢失的图标。

本版先读取动态自身互动栏的 SVG 形状、颜色、显示文字及分组间距，再在独立页面中生成完整互动栏，接到原帖截图底部。数字使用网页当前显示的值，如 10K+ 和 2.1K，不推算精确数量。读取图标时只复制绘图属性，不复制网页脚本、事件、外部资源或裁切样式。

截取原帖时临时隐藏原互动栏的绘制，保留其布局尺寸，避免外层裁切边界因卡片缩短而移到最后一张照片上；完成后恢复原样式。正文、所有配图仍采用现有截图方式。互动栏完成后再接艺人评论，烤制在完整原文下方插入中文，最后添加文字水印。

独立互动栏保持原图宽度和像素倍率、左右分组方式与数字显示，预留完整底部空间。艺人及粉丝原帖、无艺人评论、/e、/k、评论排序、框和楼中楼、补充/重烤沿用现有行为。

## 升级

1. 关闭工作台及它打开的浏览器，备份旧项目 data。
2. 下载对应系统的 ZIP，完整解压，确认 VERSION 为 3.0.0-preview9。
3. 完整替换 weverse_bot、static、docs，以及 run.py、VERSION、requirements.txt 和对应系统的两个启动文件。
4. 保留 data 和本机 .venv。Windows、Mac 的 .venv 不能互相复制。
5. Mac 双击启动工作台.command，Windows 双击启动工作台.bat。四个页面校准值继续使用原来已成功的设置。
6. **重新读取网址，再烤制。** 旧 PNG 的裁切部分无法自动补回；最近一次成功译文可复用。

Mac 包已同步包含此前只打包 Windows 的更新：粉丝原帖、无艺人评论仅原帖、浏览器恢复、移除平台翻译入口及完整动态互动栏等。
