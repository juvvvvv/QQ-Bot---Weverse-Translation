## 排版方式

真实网页仍由 Bot 截取艺人卡片。原文读取后保存其底部位置、左边距、宽度和字号。
烤制时用已安装的 Chromium 对人工译文排版，生成白底文字块，插在完整原文后、配图前。
整体高度随译文增长，原文和配图不缩放；分辨率和截图倍率未调整。

- 中文左对齐，优先使用刚抓取到的原文字号和边距。
- 手动上传或旧记录缺少排版参数时，使用通用边距和设置中的译文字号。
- 保留人工译文的换行、空行和表情；直接输入 emoji，`/e` 尚未实现。
- 用完整 Unicode 字素处理肤色、旗帜和组合 emoji。
- 文字通过 `textContent` 插入本地排版页面，不作为 HTML 执行，也不读取译文中的网址。
- 排版浏览器不访问 Weverse、不使用登录配置，仅使用系统字体或用户指定的本地字体。
- 不再生成绿色翻译框、图片内的段落标题或底部翻译整理栏。
- 文字水印移至成图中心，暂按约 20% 不透明度；清空设置中的水印文字可只核对正文版式。
  水印内容仍来自当前设置，QQ 号绑定名称和固定格式尚未实现。
  已配置的 PNG Logo 功能仍保留兼容，删除该功能属于后续需求。
- Windows 排版线程使用支持子进程的 Proactor 事件循环，避免与 WebUI 事件循环冲突。

## 在当前 Windows 项目中更新

1. 在当前工作台的运行窗口按 Ctrl+C，停止工作台。
2. 下载新源码并解压，把新包整个 `weverse_bot` 文件夹复制到当前已能正常运行的项目，替换同名文件。
   本次包含新增 `text_image.py`，需要整个文件夹一起更新。
3. 保留当前项目的 `.venv` 和 `data`。依赖清单没有改变，不用重新安装。
4. 在当前项目中双击 `启动工作台.bat`，刷新工作台页面。
5. 重新读取 `https://weverse.io/plave/artist/3-241901329?hl=zh-cn`。
   旧截图不会自动补上排版参数，所以要重新读取。
6. 在正文译文输入框填写 `漂亮的一天🙂`，点击“生成翻译图片”，下载 PNG。

Mac 同样替换整个源码文件夹并保留环境，使用 `启动工作台.command`。
Windows 以 Python 3.14、Mac 以 Python 3.13 为基准。

QQ 接通后，现有烤制指令也使用同一渲染流程：

```text
烤制 https://weverse.io/plave/artist/3-241901329?hl=zh-cn
漂亮的一天🙂
```

本轮校准版式，不添加新的指令前缀，也没有实现后续动态仓库和名称授权改版。
