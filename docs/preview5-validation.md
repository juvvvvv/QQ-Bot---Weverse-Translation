# Windows 评论排版修正版 · 3.0.0-preview5

本轮仅更新你反馈的三点，生成 Windows 包，使用 Python 3.14。依赖未变，无需重新安装；Mac ZIP 仍是 preview3。

## 改动与使用

- 评论原文保留一次，中文作为单独段落排在其后，评论框和后续内容随译文向下扩展。正文与评论的宽度、顺序和拼接方式不变。
- 楼中楼连接线从卡片顶部到下方连续延伸；保留缩进、正常圆角框、头像、名称、身份标识、时间、表情和链接样式。
- 评论仅保留自身正常互动栏，清除卡片之外多余半截图标、小箭头。动态截图排除其他区域悬浮图形，动态自身点赞与评论栏保留。
- `/k`、`/e`、补充烤制、仅保存最新成功版本、Arial 水印、自动拒绝隐私提示和会话恢复保持。

评论现在保存可重新排版的内容和已加载头像，生成时在独立文档内重新布局，没有网站脚本、登录浮层和悬浮工具栏；中文进入正常文档流，框和细线按最终卡片高度绘制。正文仍使用网页截图。

## 更新步骤

1. 关闭工作台终端和登录浏览器，备份原项目的 `data`。
2. 完整解压新版，确认 `VERSION` 为 `3.0.0-preview5`。
3. 将新版 `weverse_bot`、`static`、`docs` 完整替换到原项目，同时替换 `run.py`、`VERSION`、`requirements.txt`、`首次安装.bat`、`启动工作台.bat`。
4. 保留原来的 `data` 与 `.venv`，双击新版 `启动工作台.bat`，使用新打开的工作台页面。
5. **重新输入网址读取，再烤制。** 旧版原生评论截图缺少新版排版数据，会提示重新读取。已有最新译文仍可填回校对；原来的校准选择器无需更改。

不要直接用旧 PNG 检验新排版。纯数字、纯表情仍可单段填写 `/k`，其他段落按原来的独立一行 `+` 分隔。

## 验证范围

基于你提供的 14 条艺人评论结构，增加真实嵌套链接 DOM、原网站限高/定位样式、额外底部 SVG 与伪图标、卡片外悬浮栏的测试。检查完整原文在中文之前且只出现一次；查看真实生成的长图；逐像素检查连接线在 1 倍和 2 倍下没有任何断行。另检查跳过时原图像素不变、最新译文复用，以及旧截图明确提示重新读取。

通过真实 HTTP 服务和浏览器界面验证新的评论排版、下载、`/e`、补充新评论、重新烤制覆盖、错误段数保留已有成功版本、水印最后添加。

120 项自动回归测试全部通过；新的评论烤制界面与旧标签页/拒收 Cookie 的会话恢复两组浏览器流程通过，控制台均无错误。结果见 `preview5-test-results.txt`、`preview5-ui-results.txt` 和 `preview5-session-ui-results.txt`。这些检查在 Linux Chromium 与受控页面运行，没有在 Windows 本机执行安装器，没有直接访问你的 Weverse/QQ 会话。真实网站的当前样式、网络和 Windows 字体仍需本机验证。
