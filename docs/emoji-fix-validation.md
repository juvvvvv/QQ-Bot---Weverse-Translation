## 本机更新和复测

1. 停止工作台，在运行窗口按 Ctrl+C。
2. 下载新版本源码，解压到另一文件夹。
3. 将新版本整个 `weverse_bot` 文件夹复制到原项目，替换同名文件。
4. 保留原项目 `data` 和 `.venv`，不用重新安装依赖。
5. Windows 用原 `启动工作台.bat` 重启，Mac 用 `启动工作台.command` 重启。
6. 刷新工作台，重新读取同一条动态。旧图片不会自动更新。

先核对原文表情完整显示、头像和图片完整、没有站点遮挡。
本次仍沿用现有烤制样式；译文位于原文下方的新版排版留到下一步样张测试。
如果仍有裁切，请保留工作台下载的原始 PNG，便于与 QQ 聊天预览区分。
